# CROP Lexical Analyzer

A basic Python-based Lexical Analyzer for Cycle-Driven Resource-Oriented Programming (CROP).

## Features
- Identifies CROP reserved words and keywords
- Recognizes data types and identifiers
- Detects integer, float, string, and boolean literals
- Identifies operators and delimiters
- Detects lexical errors
- Displays tokens and lexemes using a graphical interface

## Technologies Used
- Python
- Tkinter
- VS Code

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python crop_lexer.py
```
